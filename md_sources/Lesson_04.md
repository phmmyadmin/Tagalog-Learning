__l\. The demonstrative __  <span style="color:#ff0000"> __ito__ </span>  __ \(__  <span style="color:#ff0000"> __this__ </span>  __\)__

The demonstrative Ito \(pronounced i\-to\) is used to refer to a thing that is very near or close to the person speaking\. It is followed by the linking verb  <span style="color:#ff0000"> __ay__ </span>  in a subject\-predicate sentence word order\. The linking verb ay may be shortened to  <span style="color:#ff0000"> __'y__ </span>  as it follows the word ito\. ln an inverted word order sentence where the predicate comes at the beginning\, such as the sentence “maliit ito\,” the linking verb  <span style="color:#ff0000">ay</span>  is dropped\.

__Example:__ This is John\.			lto'y si John\.

This is a child\.			lto'y bata\.

This is food\.				Ito’y pagkain\.

This is small\.			Maliit ito

This is big\. 				Malaki ito\.

__2\.	__  __THE DEMONSTRATIVE __  <span style="color:#ff0000"> __IYAN \(THAT\)__ </span>

The demonstrative <span style="color:#ff0000"> </span>  <span style="color:#ff0000">iyan</span>  <span style="color:#ff0000"> </span> \(pronounced l\-YAN\) is used to refer to a thing that is near the person spo­ken to\. It is followed by  <span style="color:#ff0000">ay</span> \.

Example:

That is Mary\.		 			 lyan ay si Mary\.

That is food\.					 lyan ay pagkain\.

That is Mary's food\.			 Iyan ay pagkain ni Mary\.

That is plenty\.				   	 Marami iyan\.

That is hot\.						 Mainit iyan\.

__3\.	THE DEMONSTRATIVE IYON \(__  <span style="color:#ff0000"> __THAT\, OVER THERE__ </span>  __\)__

The demonstrative  <span style="color:#ff0000">iyon</span>  \(pronounced I\-YON\) is used to refer to a thing that is far from both the per­son speaking and the one spoken to\.

Example:

That is Pasig River\.				 		lyon ay llog Pasig\.

That is long\.									lyon ay mahaba\.

That is clean and long\. 			 		lyon ay malinis at mahaba\.

That is clean\.								Malinis iyon\.

That is long\.									Mahaba iyon

__4\.PLURAL FORMS __  <span style="color:#ff0000"> __ITO__ </span>  __\, __  <span style="color:#ff0000"> __IYAN __ </span>  __AND__  <span style="color:#ff0000"> __ IYON__ </span>

Note that since Tagalog sentences follow a plurality rule and either or both the subject or predicate may be made plural\, sentences containing the plural forms of  <span style="color:#ff0000"> __ito__ </span>  <span style="color:#ff0000"> __\, __ </span>  <span style="color:#ff0000"> __iyan__ </span> \, and  <span style="color:#ff0000"> __iyon__ </span>  may be marked by the plural marker  <span style="color:#ff0000"> __ang __ </span>  <span style="color:#ff0000"> __mga__ </span> \. The singular forms of  <span style="color:#ff0000"> __ito__ </span> \,  <span style="color:#ff0000"> __iyan__ </span> \, and  <span style="color:#ff0000"> __iyon__ </span>  are not preceded by  <span style="color:#ff0000"> __ang__ </span> ; but the plural forms of these words are preceded by the plural article  <span style="color:#ff0000"> __ang __ </span>  <span style="color:#ff0000"> __mga__ </span> \. This and that thus become these and those\.These are good\.				Ang mga ito ay mababait\.

Those are big\.					Ang mga iyan ay malalaki\.

Those are clean\.				Ang mga iyon ay malilinis\.

<span style="color:#ff0000"> __THIS__ </span>  __ AND __  <span style="color:#ff0000"> __THAT __ </span>  __AS MODIFIERS__

The demonstratives  <span style="color:#ff0000"> __ito__ </span>  <span style="color:#ff0000"> __\, __ </span>  <span style="color:#ff0000"> __iyan__ </span> \, and  <span style="color:#ff0000"> __iyon__ </span>  can also be used as modifiers to point out or specify the sub­ject of a sentence\. It is interesting to note that when used as modifiers\, these demonstratives are placed before the noun and may also be repeated for emphasis before the linking verb  <span style="color:#ff0000"> __ay__ </span>  in a subject\-predicate sentence \(see first example\) or are the end of an inverted word order sentence \(see second exam­ple below\)\. Either sentence structure is acceptable but the first one is more formal and the second is more colloquial\.

Ang mesa <span style="color:#ff0000"> __ng__ </span>  ito ay malinis\.				This table is clean\.

lto <span style="color:#ff0000"> __ng__ </span>  mesa <span style="color:#ff0000"> __ng__ </span>   __ito__  ay malinis\.

Malaki ang bahay na iyon\. 				That house is big\.

Malaki iyon <span style="color:#ff0000"> __g__ </span>  bahay  <span style="color:#ff0000"> __na__ </span>  <span style="color:#ff0000"> </span> iyon\.

Maganda ang suot mo <span style="color:#ff0000">ng</span>  iyan\. 			Your clothes are beautiful\.

Maganda iyan <span style="color:#ff0000">g</span>  suot mo __ng__  iyan\.

Observe the use of \- <span style="color:#ff0000"> __ng\, \-g __ </span> and  <span style="color:#ff0000"> __na__ </span>  in the following phrases:

ito <span style="color:#ff0000">ng</span>  <span style="color:#ff0000"> </span> mesa <span style="color:#ff0000">ng</span>  ito

iyan <span style="color:#ff0000"> __g__ </span>  suot mo <span style="color:#ff0000">ng</span>  iyan

iyon <span style="color:#ff0000">g</span>  bahay  <span style="color:#ff0000">na</span>  iyon

In these phrase\, the connective \- <span style="color:#ff0000"> __ng__ </span>  is attached to the modifier  <span style="color:#ff0000"> __ito__ </span> \, the noun mesa\, and the pronoun  <span style="color:#ff0000"> __mo__ </span> ; the connective  <span style="color:#ff0000"> __\-g__ </span>  is attached to the modifiers  <span style="color:#ff0000">iyan</span>  and  <span style="color:#ff0000"> __iyon__ </span> ; and the connective <span style="color:#ff0000"> __ __ </span>  <span style="color:#ff0000"> __na__ </span>  <span style="color:#ff0000"> __ __ </span> comes after the noun bahay\.

The purpose of these three  <span style="color:#ff0000"> __connectives or ligature__ </span> \, to be discussed in the next lesson is to connect the ff:

a demonstrative and a noun  __\(__  __itong__  __ mesa\, __  __iyang__  __ __  __suot__  __\, __  __iyong__  __ __  __bahay__  __\)__

a noun and a demonstrative  __\(__  __bahay__  __ __  __na__  __ __  __iyon__  __\, __  __mesang__  __ __  __ito__  __\)__

a possessive pronoun and a demonstrative  __\(__  __mong__  __ __  __iyan__  __\)__

In a sentence containing the demonstratives  <span style="color:#ff0000"> __ito__ </span>  <span style="color:#ff0000"> __\, __ </span>  <span style="color:#ff0000"> __iyan__ </span>  <span style="color:#ff0000"> __\, and __ </span>  <span style="color:#ff0000"> __iyon__ </span>  <span style="color:#ff0000"> __ __ </span> and the marker  <span style="color:#ff0000"> __sa__ </span>  <span style="color:#ff0000"> </span> \(which means  <span style="color:#ff0000"> __in\, at\, on__ </span>  or  <span style="color:#ff0000"> __to\, __ </span> and is used to denote the location of an action\)\, the demonstratives  <span style="color:#ff0000"> __ito__ </span>  <span style="color:#ff0000"> __\, __ </span>  <span style="color:#ff0000"> __iyan__ </span>  <span style="color:#ff0000"> __\, or __ </span>  <span style="color:#ff0000"> __iyon__ </span>  <span style="color:#ff0000"> __ __ </span> always appear after the noun at the end of the sentence\.

Ang bata ay kumain sa mesa <span style="color:#ff0000"> __ng__ </span>  ito\.   		The child ate on this table\.

Pumunta kami sa bahay  <span style="color:#ff0000"> __na__ </span>  iyan\.			We went to that house\.

Sumakay sila sa bus  <span style="color:#ff0000"> __na__ </span>  iyon\.				They rode on that bus\.

__WORDS THAT LINK AND DESCRIBE__

A peculiar but noteworthy feature of the Tagalog language is the use of connectives or ligatures to  <span style="color:#ff0000">"link together " two adjacent words</span> \. The ligature suffixes  __\-__  <span style="color:#ff0000"> __ng__ </span>  __ __ and  <span style="color:#ff0000"> __\-g__ </span>  __ __ are attached to the  <span style="color:#ff0000">end of the first word </span> in a sequence whereas the ligature word  <span style="color:#ff0000"> __na__ </span>  <span style="color:#ff0000"> __ __ </span> is placed between the  <span style="color:#ff0000">two words</span> \.

These ligatures have no particular meaning of their own\, but merely indicate that there is a close rela­tionship between the two words and that\, generally\, one modifies the other\.

I\. THE RULES FOR USING EACH TYPE OF LIGATURE

1\.The suffix ligature \- <span style="color:#ff0000">NG</span>

The ligature \- <span style="color:#ff0000">ng</span>  is attached as a suffix to the end of  <span style="color:#ff0000">words that end in vowels\. </span>  <span style="color:#ff0000">a\,e</span>  <span style="color:#ff0000"> \,</span>  <span style="color:#ff0000">i</span>  <span style="color:#ff0000"> </span>  <span style="color:#ff0000">o\,u</span>

Ang malaki <span style="color:#ff0000">ng</span>  bahay ay isang paaralan\.   		\(malaki \+ \-ng \+ bahay\)

The  <span style="color:#ff0000">big house </span> is a school\.				big house

Marunong ang bata <span style="color:#ff0000">ng</span>  <span style="color:#ff0000"> </span> mabait\.				\(bata \+ \-ng \+ mabait\)

The good child is intelligent\.				good child

I\. THE RULES FOR USING EACH TYPE OF LIGATURE

2\. The suffix ligature \- <span style="color:#ff0000">G</span>

The ligature <span style="color:#ff0000"> \-g </span> is attached as a suffix to the end of words that  <span style="color:#ff0000">end in the consonant N\. </span>

Ang mayaman <span style="color:#ff0000">g</span>  lalaki ay mapagbigay\.		\(mayaman \+ \-g \+ lalaki\)

The rich man is generous\.				 rich man

I\. THE RULES FOR USING EACH TYPE OF LIGATURE

3\.The ligature  <span style="color:#ff0000">NA</span>

The ligature word  <span style="color:#ff0000">na</span>  is used after words that end in  <span style="color:#ff0000">consonants other than n\. </span>

Kumain siya ng  <span style="color:#ff0000">maasim</span>  <span style="color:#ff0000"> </span>  <span style="color:#ff0000">na</span>  <span style="color:#ff0000"> </span>  <span style="color:#ff0000">mangga</span> \. 		\(maasim \+  <span style="color:#ff0000">na</span>  \+ mangga\)

He/She ate a  <span style="color:#ff0000">sour mango</span> \.			Sour mango

mangga <span style="color:#ff0000">ng</span>  maasim

The quiet child is beautiful\.			quiet child
