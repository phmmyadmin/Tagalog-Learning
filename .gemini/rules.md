# Mandatory Agent Workflow Rule

Before starting ANY feature implementation in this repository, you MUST follow the 4-stage Skill Workflow:

1. `feature-planner`: Ask questions and formulate plan.
2. `project-task-creator`: Create tasks in GitHub Project V2 (@phmmyadmin's tasks).
3. `feature-executor`: Create feature branch, set task status to 'In Progress' (47fc9ee4), code, verify build, commit, push, create PR.
4. `feature-reviewer`: Audit code, refactor if needed, verify build, merge PR, pull to main, delete feature branch, set task status to 'Done' (98236657).
